# Implementation Plan: Natural-Language Reminder Agent

**Branch**: `002-natural-language-reminder-agent` | **Date**: 2026-11-07 | **Spec**: [spec.md](./spec.md)

## Summary

Build a small reminder-intent parser that calls a configured OpenAI-compatible model and validates its structured response through one evaluation pipeline. The application does not persist reminders or perform side effects. Evaluation uses the fixed dataset and predeclared structural, invariant, semantic, and aggregate thresholds in the specification.

## Technical Context

**Language/Version**: Node.js 20 or newer, JavaScript ES modules

**Primary Dependencies**: Node.js built-in `fetch`, `node:test`; no third-party runtime dependency

**Storage**: None; dataset and result artifacts are local JSON files

**Testing**: Built-in Node test runner for parser, schema, invariant, scoring, and dataset coverage

**AI Provider**: Configurable OpenAI-compatible chat-completions endpoint using environment variables; credentials remain local

**Performance Goals**: One model request per evaluation case, sequentially; stop on provider failure to avoid repeated failed calls

## Design

1. Load and validate the dataset and required environment configuration.
2. For each case, submit the fixed system contract and input to the configured model without tool definitions.
3. Parse only the model's JSON response; classify transport/provider errors separately from invalid output.
4. Run structural validation, specification-derived invariants, and a per-case semantic rubric.
5. Aggregate results using the fixed formula and threshold from the specification.
6. Write non-secret run metadata, outputs, layer results, and errors to `Part-1B/evidence/eval-results.json`.

## Validation

- Unit tests run without an external model and must not be mistaken for live evaluation evidence.
- The live harness runs the real configured model on the fixed dataset and records provider errors explicitly.
- No baseline results or human acceptance decision will be fabricated when no configured model is available.
